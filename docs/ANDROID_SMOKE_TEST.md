# Android 预览版验收记录

请在测试设备上操作，避免清理日常使用的歌单。每项记录设备型号、Android 版本、APK 版本、结果和复现步骤。尚未执行的项目保持空白。

## 安装与升级

- [x] 全新安装签名 APK，启动后没有崩溃或黑屏（Mi 10 / Android 13，2026-09-24）。
- [ ] 用同一签名密钥、递增构建号的下一版覆盖安装，歌单和设置仍在。
- [ ] Android 7.0（最低支持版本）和一台较新 Android 设备均可启动。

## 音乐库与播放

- [ ] 从系统文件选择器导入 MP3 和 FLAC，歌单中可以播放。
- [ ] 关闭应用并重新打开后继续播放；清除**应用缓存**后仍可播放已导入歌曲。
- [ ] 导入重复文件不产生重复歌单条目；存储空间不足时出现错误提示。
- [ ] 连续播放、暂停、下一首、拖动进度、单曲循环和随机播放正常。
- [ ] 息屏及切到后台 30 分钟后播放正常；耳机拔出、蓝牙断开和音频焦点变化后状态合理。
- [ ] 竖屏、横屏、系统返回和通知控制没有遮挡、崩溃或明显卡顿。
- [ ] 断网时本地歌曲照常播放，网络歌词失败不会阻止播放。

## 备份与恢复

- [ ] 导出歌单 JSON，确认文件不包含本机绝对路径或音乐文件内容。
- [ ] 在另一台测试设备导入 JSON，重新选择音乐文件后，匹配数量和歌单内容正确。
- [ ] 故意少选一首，应用报告未找到数量，原有歌单不被删除；再次导入并补选后可补齐。
- [ ] 导入损坏或未知版本的 JSON 时，现有歌单不被覆盖。
