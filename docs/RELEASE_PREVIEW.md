# Myune Music Android 预览版 0.9.3+1

从 Myune Music 的本地工程提取的 Android 专用 Flutter 项目。保留原项目的 Apache License 2.0 与来源说明。

## 本次内容

- Android 独立入口与构建工程，包名 `com.myune.music.preview`。
- 本地音乐、歌单、歌词与沉浸式播放界面。
- 将 Android 文件选择器中的音乐从缓存复制到应用持久目录；尽可能迁移仍存在的旧缓存文件。
- 提供不包含音乐文件的歌单 JSON 备份，以及按内容指纹匹配的恢复流程。
- 增加备份测试、Android/Rust 自动构建和本地签名发布脚本。
- 听歌房使用为本项目新生成的插画；公开源码与安装包不包含从第三方网站取得的场景图或 MiSans 字体文件。

## 已知限制

- 换机恢复时需要重新选择原始音乐文件；未匹配到的歌曲不会加入歌单，可稍后再导入同一备份补齐。
- 预览版使用独立包名，不会自动继承原 Android 安装中的歌单数据。
- 前一版签名包已在小米 Mi 10 / Android 13 验证安装、FLAC 导入、播放、15 秒后台播放和重启后歌曲保留。当前发布的 APK 已在同一设备覆盖安装，并显示主界面和专注模式；这次未重新验证播放与后台行为。30 分钟后台播放、清除缓存、耳机/蓝牙中断及跨设备恢复仍待验收。测试记录见 `docs/ANDROID_SMOKE_TEST.md`。
- GitHub Actions 已在公开仓库的全新检出上通过分析、测试与 Android/Rust 构建。

本预览版附签名 ARM64 APK 和 SHA-256。
