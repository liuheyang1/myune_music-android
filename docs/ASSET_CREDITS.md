# 素材来源

- 应用代码和 `assets/images/icon/` 中的图标基于 [xiaobaimc/myune_music](https://github.com/xiaobaimc/myune_music)，遵循仓库中的 [Apache License 2.0](../LICENSE)。本 Android 版另行修改了移动界面、播放流程、导入与歌单备份。

- `rust_builder/cargokit/` 保留其上游 [许可文件](../rust_builder/cargokit/LICENSE)。其他依赖以各自的许可为准。

仓库和安装包不含音乐文件、用户导入的专辑封面、从第三方网站下载的场景图或 MiSans 字体文件。
